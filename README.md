## 📊 Sobre a Certificação

O **Google Data Analytics Professional Certificate** é um programa profissional oferecido pelo Google através da Coursera, focado em desenvolver habilidades práticas em análise de dados.

### 🎯 Competências Desenvolvidas

- **SQL** - Extração, análise e qualidade de dados
- **Python** - Pandas, NumPy, análise de dados
- **Tableau** - Visualizações e dashboards estratégicos
- **Excel** - Análise e relatórios
- **R** - Programação estatística
- **Data Cleaning** - Limpeza e transformação de dados
- **Data Visualization** - Storytelling com dados
- **Statistical Analysis** - Análise descritiva e inferencial

## 🏆 Capstone Project: Cyclistic Bike-Share Analysis

Como projeto final, realizei análise completa de dados de bike-share para responder à pergunta de negócio:

> **"Como converter ciclistas casuais em membros anuais e maximizar a lucratividade?"**

### 📊 Principais Resultados

- **5 milhões** de viagens analisadas
- **97%** de diferença no tempo de uso (casuais vs membros)
- **$2.6M** de impacto projetado Ano 1
- **ROI 4:1** nas recomendações estratégicas

### 🔗 Portfolio Completo

- Documentação completa metodologia
- Apresentação executiva (14 slides)
